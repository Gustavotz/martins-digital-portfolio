# Martins Digital — Portfolio

Portfólio profissional de Gustavo Martins para apresentação de projetos, soluções digitais e experiências desenvolvidas.

**Site:** https://martinsdigital.site

## Objetivo

Reunir em um único lugar os projetos, cases e áreas de atuação da Martins Digital — experiências web, produtos digitais, automação e aquisição — apresentados de forma clara para quem avalia uma parceria ou contratação.

## Desenvolvimento web

O portfólio é uma aplicação web de página única, construída para apresentar conteúdo extenso (áreas de atuação, cases, serviços e contato) em uma navegação contínua e organizada por seções.

## Responsividade

A interface foi pensada para desktop e mobile, adaptando layout, tipografia e mídias dos cases a diferentes tamanhos de tela.

## Identidade visual

- Linguagem visual própria, com hierarquia tipográfica bem marcada.
- Tipografia baseada nas famílias Geist e Geist Mono.
- Numeração e rótulos técnicos para orientar a leitura das seções e dos cases.

## Animações e interação por scroll

As seções e elementos dos cases entram em cena conforme a rolagem da página, criando uma leitura progressiva do conteúdo. A detecção de visibilidade dos elementos é feita no navegador com a Intersection Observer API.

## Organização em cases

Cada projeto é apresentado como um case, com contexto, tipo de projeto, atuação e principais entregas. Os cases atuais incluem:

- **Quitex Brasil** — experiência web interativa orientada por scroll.
- **Martins Prospect** — ferramenta própria de prospecção (MVP).
- **Commercial Experience** — projeto demonstrativo de jornada comercial.
- **Automation & Digital Operations** — fluxos de atendimento, bots e aquisição.

## Tecnologias

Tecnologias verificáveis no site publicado:

- React
- CSS
- Intersection Observer API
- Google Fonts (Geist / Geist Mono)

O código-fonte completo não está sendo publicado neste showcase. Este repositório apresenta o projeto em alto nível; a versão em produção pode ser vista em https://martinsdigital.site.
